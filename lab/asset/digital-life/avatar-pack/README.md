Hongwu Lab Digital Avatar Pack v3 (Transparent Rebuild)

Use this package to replace your current asset folder.

Replace folder:
asset/digital-life/avatar-pack/

Included states:
- modes: base / helmet / sunglasses / headset
- actions: idle / walk / work / interact / travel / run / jump / read
- expressions: default / smile / thinking / working / interact / travel / happy / confused / surprised / angry / shy / wave
- every state contains 4 transparent WebP frames
- animated/*.webp are ready-to-use loops for the website selector
- source_sheets/ contains the generated transparent sprite sheets

index.html in the zip has also been updated to remove the old boxed avatar frame and use a transparent blended presentation.
