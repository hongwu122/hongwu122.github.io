# poetry/data — 格律与韵部数据

本目录存放个人网站（`lab/poetry`）中「格律 · 韵部知识与自动校稿」功能所用的数据文件，共 8 个：

| 文件 | 内容 | 用途 |
|---|---|---|
| `Pingshui_Rhyme.json` | 平水韵 · 106 韵韵字表 | 近体诗（古典诗）韵部检字、韵脚归韵 |
| `Cilin_Rhyme.json` | 词林正韵 · 19 部韵字表 | 词韵部检字、韵脚归韵 |
| `Xinyun_Rhyme.json` | 中华新韵 · 14 韵韵字表 | 各体裁的现代新韵对照 |
| `Word_Tune.json` | 单字平仄字典（8232 字） | 近体诗逐字平仄校对 |
| `Ci_Word_Tune.json` | 词用单字平仄字典（5037 字，含词林韵部） | 词逐字平仄校对；曲校稿的后备平仄 |
| `Ci_Tunes.json` | 词谱库（818 个词牌） | 词牌索引、词谱展示、词作逐句对照 |
| `Qu_Tunes.json` | 曲牌库（13 个常用曲牌） | 曲牌索引、曲谱展示、曲作逐句对照 |
| `Zhongyuan_Yinyun.tsv` | 中原音韵音系表（5878 行） | 曲韵检字、曲逐字平仄核对、曲韵部推测 |

> 加载方式：页面 `index.html` 在 `RHYME_DATA_URLS` 中声明各文件路径（相对 `./data/`），**按需懒加载**——只有触发「格律检测 / 韵部检字 / 词曲谱对照」等对应功能时才 `fetch` 对应文件。`Zhongyuan_Yinyun.tsv` 以纯文本读取后由页面自行解析，其余 JSON 直接 `JSON.parse`。

## 1. Pingshui_Rhyme.json — 平水韵韵字表

**结构**：五级嵌套，`声部 → 韵目 → 韵字数组`。

```json
{
  "上平声部": { "一东": ["东", "同", "铜", ...], "二冬": ["冬", "农", "宗", ...], ... },
  "下平声部": { ... },
  "上声部":   { ... },
  "去声部":   { ... },
  "入声部":   { "入声一屋": [...], "入声二沃": [...], ... }
}
```

**注意**：入声部键名带「入声」前缀（`入声一屋`～`入声十七洽`）；上声部缺「三讲」韵目（实际收录 28 目），全表共 105 个韵目键。

**页面用法**：
- 「韵书总表」中点击韵目展开全部韵字；
- 「韵部查询」输入汉字反查所属平水韵韵部；
- 古典诗「自动校稿」按偶数句（及首句入韵情况）韵脚推测主韵部。

## 2. Cilin_Rhyme.json — 词林正韵韵字表

**结构**：`韵部（第一部～第十九部）→ 平声/仄声 → 韵字数组`。

```json
{
  "第一部": { "平声": ["东", "同", "童", ...], "仄声": ["董", "懂", "动", ...] },
  "第二部": { ... },
  ...
}
```

**页面用法**：韵书总表展开某部平/仄韵字；韵部查询；词作校稿时按韵脚推测词林正韵韵部。

## 3. Xinyun_Rhyme.json — 中华新韵韵字表

**结构**：`韵部（一麻～十四姑）→ 平/仄 → 韵字数组`。

```json
{
  "一麻": { "平": ["啊", "腌", "扒", ...], "仄": ["把", "靶", "礤", ...] },
  "二波": { ... },
  ...
}
```

**页面用法**：韵部查询；古典诗、词、曲三类校稿中均作为「中华新韵」对照，给出今音视角的韵部推定。

## 4. Word_Tune.json — 单字平仄字典（近体诗用）

**结构**：`汉字 → "平" | "仄"`，共 8232 字。

```json
{ "东": "平", "同": "平", "铜": "平", "中": "平", ... }
```

**页面用法**：古典诗校稿时按诗句逐字查平仄，与「律诗/绝句正格」句式比对，标出不合平仄的字（多音字按"中"处理不硬判）。

## 5. Ci_Word_Tune.json — 词用单字平仄字典

**结构**：`汉字 → { "tune": "平"|"仄", "rhyme": "第X部" }`，共 5037 字，`rhyme` 对应词林正韵韵部。

```json
{ "东": { "tune": "平", "rhyme": "第一部" } }
```

**页面用法**：
- 词校稿：逐字比对词谱平仄；
- 曲校稿：当某字在《中原音韵》中查不到时，作为后备平仄信息来源（`fallbackMap`），避免误判。

## 6. Ci_Tunes.json — 词谱库

**结构**：`词牌名 → { desc, formats[] }`，共 818 个词牌。每个格式含句式总览、作者、逐字谱与换片标记：

```json
{
  "竹枝": {
    "desc": "唐教坊曲名。……",
    "formats": [
      {
        "sketch": "单调十四字，两句两平韵",
        "author": "皇甫松",
        "tunes": [
          { "tune": "平" },
          { "tune": "仄", "rhythm": "枝" },
          { "tune": "平", "rhythm": "韵" },
          { "tune": "仄", "rhythm": "女", "shift": "true" }
        ],
        "desc": "《尊前集》载皇甫松《竹枝》词六首……"
      }
    ]
  }
}
```

字段说明：`tune` 平仄（`平`/`仄`/`中`）；`rhythm` 标注衬字/和声（含"韵"表示叶韵）；`shift` 标记换片。

**页面用法**：词牌索引与词谱详情展示（○●◇ 符号谱 + 谱例句）；词校稿时自动挑选与作品句数、字数、平仄最接近的一体，逐句给出匹配率与不合之处。

## 7. Qu_Tunes.json — 曲牌库

**结构**：`曲牌名 → { desc, formats[] }`，收录 13 个常用曲牌（天净沙、山坡羊、水仙子、折桂令等）。每个格式含句式、押韵与谱例：

```json
{
  "天净沙": {
    "desc": "北曲越调小令。当前收录正格与常见变格；五句二十八字，逐句押韵。",
    "formats": [
      {
        "name": "正格",
        "note": "五句，四平韵、一叶韵",
        "source": "乔吉《天净沙·一从鞍马西东》",
        "pattern": ["平中中仄平平", "仄平平仄平平", ...],
        "rhyme":  [true, true, true, true, true],
        "example": ["一从鞍马西东", "几番衾枕朦胧", ...]
      }
    ]
  }
}
```

**页面用法**：曲牌索引与曲谱展示；曲校稿时逐句对照曲牌句式，其中「上、去、入」按严格位置单独核对（比普通平仄更严）。

## 8. Zhongyuan_Yinyun.tsv — 中原音韵音系表

**结构**：TSV（制表符分隔），5878 行，首行为表头：

```
小韻	字	聲母	韻母	聲調	杨耐思	宁继福	薛凤生(音位)	unt(音位)	unt	釋義	校註
東	東	端	東鍾合	陰	tuŋ	tuŋ	twoŋ	tuŋ	tuŋ
```

字段说明：`小韻` 声韵调相同的一组字；`字` 同小韻下的各字；`聲母` 中古声母；`韻母` 韵部（含开合，如"東鍾合"）；`聲調` 阴平/阳平/上/去；其后四列是不同学者的拟音（杨耐思、宁继福、薛凤生音位、unt），`釋義`/`校註` 为释义与校勘注记。

**页面用法**：
- 页面加载时解析为 `字 → [{韵部, 声调, 韵母}]` 映射（韵部由韻母前两字映射到简体韵部名，如"東鍾"→"东钟"）；
- 「韵书总表 · 中原音韵」点击韵部，按声调分组显示该部韵字；
- 曲校稿：逐字查声调核对曲谱平仄（阴/阳平=平，上/去=仄），并据此推测曲的韵部。
