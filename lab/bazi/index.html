算法边界
阳历四柱
年柱按立春、月柱按节气月、日柱按固定锚点推六十甲子、时柱按五鼠遁。与原 Python 的 sxtwl 思路对齐，但V3 优先使用 tyme4ts 1.5.2 的寿星天文历节气算法；若远程模块加载失败才降级到旧近似公式，并在顶部明确显示“降级引擎”。临节气案例仍建议用 sxtwl 独立复核。
农历输入 · 已接入
已可输入农历年月日、闰月与时辰；浏览器用 Intl 中国农历历法反查阳历，再进入同一套四柱算法。Chrome/Edge 新版可离线使用；不支持时会提示。
经纬度 / 真太阳时 · 已计算参考值
已接入经度、时区、地方经度修正与均时差，基本信息会显示真太阳时参考。V3 已增加“标准民用时间 / 地方平太阳时 / 真太阳时”开关，选择后的时间会真正进入时柱与换日计算；均时差使用 NOAA 常见近似式，极靠近时辰边界仍应交叉复核。
